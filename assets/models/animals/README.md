# Chicken model

Place the PS1 chicken GLB here as `chicken.glb`.

- Source: https://sketchfab.com/3d-models/ps1-chicken-289cf2bd644b4480b9a57e7bd2e89cbb
- Author: RetroDesignHive (RDDev)
- License: CC Attribution 4.0 (http://creativecommons.org/licenses/by/4.0/) — credit the author, commercial use allowed

The game loads `assets/models/animals/chicken.glb` for ambient chickens on plains. If the file is missing, chickens simply won't spawn.
